## What is public

Only the website, product screenshots using synthetic data, checksum and download metadata are tracked here. **The application source project, development files, private launch kit, credentials and user profiles are not published.** GitHub-generated source archives contain the website only. A downloaded Electron installer can still be inspected; source exclusion is not a guarantee against reverse engineering.

Public visitors have read access, not permission to push changes to this repository. Forks or proposed pull requests cannot modify the official repository without maintainer action. No application open-source license is granted by publishing this download. Third-party licenses remain applicable.

## Support and data

[Report an issue](https://github.com/qumbarraza/ai-pilot/issues) with version, Windows version and reproduction steps. Do not post API keys or meeting content. Screen/audio are sent to the selected provider; use authorized content. Closing controls keeps capture running in the tray. Stop & clear or tray Exit ends capture.

The published page is static and does not request API keys. The full build workspace remains local.
